# 🏗️ INTERCERT - Certificaciones ISO para Construcción

Landing page profesional para INTERCERT, especialistas en certificaciones ISO de alta calidad para empresas constructoras en Cajamarca, Perú.

## 🌟 Características

- ✅ Diseño responsive y moderno
- ✅ Formulario multi-step con validación
- ✅ Integración con HubSpot CRM
- ✅ Notificaciones por email con Resend
- ✅ Carrusel animado de empresas certificadas
- ✅ Animaciones de conteo para estadísticas
- ✅ Video de YouTube embebido
- ✅ Modal de éxito personalizado
- ✅ Integración con Calendly

## 🎯 Certificaciones

- ISO 9001 - Gestión de Calidad
- ISO 14001 - Gestión Ambiental
- ISO 45001 - Seguridad y Salud Ocupacional
- ISO 37001 - Gestión Antisoborno

## 🔧 Configuración Local con Docker

1. Clona el repositorio:
```bash
git clone https://github.com/tu-usuario/intercert-landing.git
cd intercert-landing
```

2. Crea los archivos de configuración (no incluidos en el repo):
   - `config-resend.php`
   - `config-hubspot.php`
   - `config-google-sheets.php`

3. Inicia Docker:
```bash
docker-compose up -d
```

4. Accede a: `http://localhost:8080`
